# TOGA — Learn Module

## Commit 7 — Drift/SQLite Persistence

This milestone establishes local persistence using Drift on SQLite.

### Architecture

```text
Presentation
    ↓
Riverpod / Services
    ↓
Feature Repository
    ↓
Drift AppDatabase
    ↓
SQLite
```

The repository maps generated database rows into independent domain models so database types do
not leak into the feature/domain layer.

### Learning hierarchy

```text
Subject
  └── Chapter
       └── LearningUnit
            ├── ContentBlock
            └── KnowledgeCheck
```

The Radio Navigation seed contains seven learning units and three inline knowledge checks.

### Generate Drift code

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
```

`lib/database/app_database.g.dart` is generated by Drift and should not be edited manually.
